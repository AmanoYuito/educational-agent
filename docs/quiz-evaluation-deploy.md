# リアルタイム出題の計測機能をサーバーへ反映

更新対象は `amano@160.251.180.133` の `~/aituber-kit` です。
更新は今回変更したソース、操作説明、Mac補助ファイルを除外する `.dockerignore` です。`.env`、Dockerfile、Docker Compose設定、依存パッケージ、DBデータは配布物に含みません。

`._difyChat.ts` などのMac補助ファイルがサーバーに残っていても、Dockerのビルド対象から除外します。補助ファイル自体を削除する必要はありません。

サーバーへ転送済みの更新ディレクトリから、Macのターミナルで次を実行します。

```bash
ssh -t amano@160.251.180.133 'bash ~/aituber-quiz-evaluation-update-20260925/scripts/deploy-quiz-evaluation.sh'
```

サーバーのsudoパスワードを求められたら、そのターミナルに入力してください。

スクリプトは、配布ファイルと更新前ファイルのチェックサム照合、DBと対象ソースのバックアップ、現在のアプリイメージの保持、新イメージのビルド、appコンテナのみの入れ替え、管理画面・APIの応答確認を行います。ビルド中は既存アプリを動かしたままにし、入れ替え時は短時間接続が途切れる可能性があります。

失敗時は変更したソースを戻し、入れ替え開始後であれば旧イメージでappの起動を試みます。DBの自動復元・削除は行いません。バックアップ先は実行時に表示されます。サーバー側で対象コードが変更されていた場合は上書きせず停止します。

完了後はブラウザーを再読み込みして管理者でログインし、「出題比較」から計測を開始します。初回のDBアクセスで計測用テーブルが作成されます。Difyの接続先やモデルは変更しません。

実際の問題生成・CSV取得は、[操作手順](quiz-evaluation.md) に沿って確認してください。

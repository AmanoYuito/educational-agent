# 選択肢表示と問題モードの帽子をまとめて反映

更新内容は、出題比較画面の問題文の下への選択肢表示、CSVの選択肢A〜D列、問題モードのわんこへの帽子表示です。選択肢は既存のDB記録に保存されているため、DBの構造変更や既存記録の書き換えは不要です。

更新対象は `amano@160.251.180.133` の `~/aituber-kit` です。配布物は `~/aituber-quiz-avatar-update-20260925` に転送済みです。

Macのローカルターミナルで実行します。

```bash
ssh -t amano@160.251.180.133 'bash ~/aituber-quiz-avatar-update-20260925/scripts/deploy-quiz-avatar.sh'
```

すでにSSH接続していて、プロンプトが `amano@vm-59b065df-a1` の場合は、次だけ実行します。

```bash
bash ~/aituber-quiz-avatar-update-20260925/scripts/deploy-quiz-avatar.sh
```

求められたsudoパスワードはターミナルへ入力します。パスワードの文字は画面に表示されません。

スクリプトはチェックサム照合、DBと対象ソースのバックアップ、旧アプリイメージの保持後にビルドし、appだけを入れ替えます。ビルド中は旧アプリが稼働し、切り替え時のみ短時間の中断があります。失敗時は対象ソースを戻し、切り替え後なら旧イメージでの起動を試みます。DBの自動復元・削除はしません。対象ファイルが別途変更されていた場合は停止します。

「反映完了」の後、ブラウザーを再読み込みして確認します。

- 出題比較の「記録を更新」で、保存済みの問題の下に選択肢が表示されること。
- CSVを再ダウンロードし、選択肢A〜Dの各列が入っていること。既存の選択肢JSON列も残ります。
- 問題モードではわんこに帽子が表示され、採点後に通常会話へ戻ると外れること。

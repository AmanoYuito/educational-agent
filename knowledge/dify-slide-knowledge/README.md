# コンピュータシステム2 出題用スライドナレッジ

第3回はスライド3〜38、第4回はスライド3〜37を、1スライドにつき1つのMarkdownにしています。表紙と「本日の講義内容」は含みません。ファイル名と本文先頭の両方に講義回・スライド番号を記録します。補足用のWordナレッジにはスライド番号を付ける必要はありません。

元資料は `public/materials/computer-systems-2/lesson-03/material.pdf` と `lesson-04/material.pdf` です。生成し直す場合は、`scripts/build-slide-knowledge.py` を pypdf が使えるPythonで実行してください。

## Difyへの反映

1. 各回のスライド用データセットに、該当する `lesson-03` または `lesson-04` のMarkdownファイルを登録します。1ファイルが1チャンクになる設定で、見出しとスライド番号がチャンク本文に残っていることをプレビューで確認します。
2. 既存のPDF由来の文書と混在させると、番号なしのチャンクが引き続き出題対象になります。検証用データセットを先に作り、問題生成の根拠とスライド番号を確認してから切り替えてください。
3. 新しいデータセットIDへ切り替える場合は、`src/config/lessons.ts` の `datasetId` と `src/config/questionKnowledge.json` の該当IDを揃えます。補足Wordの `referenceDatasetIds` はそのままで構いません。
4. 切り替え後に新規生成・保存した問題からスライド番号が付きます。既存の問題は参照番号が未記録のため、必要なら再生成してください。

図や表が主体のスライドはPDFの文字抽出だけでは説明が不足することがあります。特に本文の短いページは元PDFと照合して補足してから登録してください。アプリは本文が極端に少ないMarkdownを出題候補から除きます。

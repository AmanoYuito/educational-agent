## Difyへの反映

1. Difyには `bundles/cs2-lesson-03-slides.md` と `bundles/cs2-lesson-04-slides.md` を、それぞれ別のスライド用データセットに登録します。各スライドは `#` 見出しで始まります。「汎用」チャンク設定の区切り文字を `***`、最大チャンク長を1024文字にし、第3回は36チャンク、第4回は35チャンクで、各チャンクにスライドIDと本文が入ることをプレビューで確認します。DifyはMarkdownの `#` を索引用テキストから除きますが、見出しの文字列は残ります。標準の改行区切りでは番号と本文が別のチャンクに分かれます。文書枠に余裕があれば `lesson-03` または `lesson-04` のMarkdownを1ファイルずつ登録する方法も使えます。
2. アプリが参照する第3回データセットIDは `af7274e8-81ab-47de-ba0f-75700f99e89f`（Dify表示名 `コンシス第3回_スライド別_学習用`）、第4回は `09b9b1b2-95c4-4c63-b5a7-95fc23a44721` です。統合文書は第3回36チャンク・第4回35チャンクで、全チャンクのスライドIDと本文を確認済みです。第3回は現在のDifyワークスペースに新規登録し、別ワークスペースの旧データセット `29d449a2-dcd6-4b37-b81f-7ac210f7e8dc` は残しています。第4回の先に登録した個別文書は削除せず無効化しています。

ロック変数による相互排除
• プロセス間でロック変数 (lock) を共有
• lock == 0 の場合:
• (際どい領域にプロセスはない )
lock = 1 と設定して際どい領域に入る
• 際どい領域から出る時に lock = 0 とする
• lock == 1 の場合:
• (際どい領域にプロセスが入っているとして ) lock=0 となるのを待つ
• 問題点: 安全なアルゴリズムではない
• 複数の機械語命令で実行されるため，命令間で割込みが発生する可能性あり
• あるプロセスがlock == 0 を確認して，lock=1 とする間に他のプロセスが
割り込んだら????
• (上記の問題を避けるためには，不可分な ) 同期基本命令を利用

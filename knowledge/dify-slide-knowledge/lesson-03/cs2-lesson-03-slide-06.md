プロセス生成の概要：プロセスはどのように作られるのか？
• OSがプログラムをメモリにロードし，
実行単位（プロセス）を作成
• 新しいプロセスは既存のプロセス（親）によって生成される
• Unix系では，fork() システムコールで新しいプロセスを生成
• 親プロセスは複数の子プロセスを
持つことができる
• システム全体ではプロセスツリー
（階層構造）を形成する
pid_t pid = fork();
if (pid == 0) {
// 子プロセスの処理
} else {
// 親プロセスの処理
}
